##  How to Use These Resources

### When Reading a Document

1. **Use Table of Contents** - Jump to relevant section
2. **Follow Links** - Blue text = related document
3. **Review Examples** - Code blocks show real usage
4. **Try It Out** - Run commands/tests as you read
5. **Search** - Use Ctrl+F to find keywords

### When Learning

**Day 1 - Setup**:
- Read: README.md (30 min)
- Follow: SETUP_GUIDE.md steps (45 min)
- Run: First test (15 min)
- **Checkpoint**: Smoke test passes 

**Day 2 - Understand**:
- Read: PROJECT_STRUCTURE.md (45 min)
- Review: Example tests in code
- Create: Simple new test
- **Checkpoint**: New test passes 

**Day 3 - Best Practices**:
- Read: CONTRIBUTING.md (30 min)
- Review: Code style section
- Refactor: A test for better style
- **Checkpoint**: Code follows standards 

### When Debugging

1. **Search FAQ** - Ctrl+F for error message
2. **Check Quick Reference** - Common commands
3. **Review Logs** - `reports/logs/execution.log`
4. **Check Screenshots** - Visual evidence
5. **Ask Question** - Use FAQ format
